# FinTrack 💰

A modern and responsive personal finance dashboard built with **React + Vite**.

FinTrack helps users track income and expenses, manage transactions, analyze spending patterns, and organize financial data through a clean dashboard interface.

## ✨ Features

- 🔐 Login & Register
- 📊 Financial dashboard
- 💸 Add, edit and delete transactions
- 🔎 Search and filter transactions
- 📈 Income & expense analytics
- 🥧 Expense category charts
- 🗂️ Dynamic expense and income categories
- 🔔 Toast notifications
- 👤 Profile settings
- 🔔 Notification preferences
- 📅 Custom date picker
- 🎯 Custom category & payment method dropdowns
- 💾 LocalStorage data persistence
- 📱 Fully responsive design
- 🛡️ Protected routes

## 🛠️ Tech Stack

- React
- Vite
- React Router
- Recharts
- React Icons
- JavaScript
- CSS
- LocalStorage

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the project

```bash
cd fintrack
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown in the terminal.

## 📁 Main Pages

| Page | Description |
|---|---|
| Login | User authentication |
| Register | Create a new account |
| Dashboard | Financial overview and charts |
| Transactions | View, search, filter and manage transactions |
| Add Transaction | Add or edit income and expenses |
| Analytics | Detailed financial analysis |
| Categories | Category-wise transaction overview |
| Settings | Profile and application preferences |

## 💾 Data Storage

FinTrack currently uses **Browser LocalStorage** to store:

- User information
- Login status
- Transactions
- Notification preferences
- Profile settings

> This project uses LocalStorage for demonstration and portfolio purposes. It is not intended as production-grade authentication or financial data storage.
